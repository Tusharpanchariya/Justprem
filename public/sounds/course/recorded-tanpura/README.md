# Course tanpura recording

`course-tanpura-c.mp3` is copied from the recording supplied in the project audio folder:
`sounds&music/Deep Tanpura Atmosphere ➤ in C - Sacred Soundscape for musicians - Joy of Resonance.mp3`.

The course player streams this C-tuned recording on demand. It uses playback-rate pitch shifting to offer Sa choices A, A#, B, C, C#, and D; C plays at the source pitch. Loop playback is enabled by default and can be turned off in the player.
